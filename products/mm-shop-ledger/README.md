# ဆိုင်စာရင်း Pro — Myanmar Shop Ledger

မြန်မာဆိုင်ငယ်များအတွက် offline-first စာရင်းသွင်း App MVP။

## ပါဝင်သောလုပ်ဆောင်ချက်များ
- ကုန်ပစ္စည်း၊ လက်ကျန်၊ ဝယ်ဈေး၊ ရောင်းဈေး ထည့်/ဖျက်ခြင်း
- အရောင်းမှတ်တမ်းတင်ပြီး လက်ကျန်အလိုအလျောက်လျှော့ခြင်း
- ယနေ့ရောင်းရငွေနှင့် အမြတ်ခန့်မှန်းချက်
- အကြွေးစာရင်းနှင့် ငွေချေပြီးကြောင်း မှတ်သားခြင်း
- JSON Backup ထုတ်/ပြန်သွင်းခြင်း
- PWA service worker ဖြင့် offline cache အခြေခံ

## စမ်းသပ်ရန်
index.html ကို browser ဖြင့်ဖွင့်ပါ။ PWA install/offline စမ်းသပ်ရန် HTTPS hosting လိုအပ်သည်။

## ကန့်သတ်ချက်
ဒေတာကို လက်ရှိ browser/device ၏ localStorage ထဲတွင်သာ သိမ်းထားသည်။ Cloud sync, multi-user, receipt printing, password security, audit log မပါသေးပါ။ ရောင်းချမီ Android စက်အမျိုးမျိုးတွင် စမ်းသပ်ပြီး backup/restore ကို အတည်ပြုရမည်။

## ရောင်းချရေးစိတ်ကူး
ဆိုင်တစ်ဆိုင်ချင်းအတွက် ဆိုင်အမည်/လိုဂို/အရောင် ပြောင်းပေးသည့် branded copy အဖြစ် one-time setup fee ဖြင့် စမ်းသပ်ရောင်းချနိုင်သည်။ ဝယ်သူစိတ်ဝင်စားမှုကို အရင်စစ်ပြီးမှ ဈေးနှုန်းသတ်မှတ်ရန်။
