ဆိုင်ငယ်၊ အွန်လိုင်းရောင်းချသူနဲ့ ကိုယ်ပိုင်လုပ်ငန်းတွေအတွက် အသုံးဝင်တဲ့ Mini App ၁၀ မျိုး။ ဖုန်း Browser မှာ တိုက်ရိုက်စမ်းသုံးနိုင်ပါတယ်။

အသုံးပြုရန် သိထားရမည့်အချက်
ဒီ Mini Apps တွေက Demo/အခြေခံအသုံးပြုနိုင်တဲ့ Web Tools ဖြစ်ပြီး ဒေတာကို ဒီဖုန်း Browser ထဲမှာသာ သိမ်းတယ်။ ဖုန်းပြောင်းခြင်း၊ Browser Data ရှင်းခြင်းမပြုမီ Backup လုပ်ပါ။ Cloud Sync၊ အွန်လိုင်းငွေလက်ခံမှုနဲ့ Paid License စနစ် မချိတ်ဆက်ရသေးပါ။

အသုံးစရိတ်စာရင်း
