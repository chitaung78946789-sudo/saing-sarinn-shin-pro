ဘာတွေလုပ်နိုင်သလဲ

🧾 အရောင်းစာရင်း
ရောင်းချမှုနဲ့ ယနေ့ရောင်းရငွေကို မှတ်တမ်းတင်နိုင်သည်။
📦 ကုန်ပစ္စည်း
ဝယ်ဈေး၊ ရောင်းဈေးနဲ့ လက်ကျန်အရေအတွက်ကို စီမံနိုင်သည်။
🤝 အကြွေးစာရင်း
ရရန်ရှိငွေကို သီးခြားကြည့်ပြီး ငွေချေပြီးကြောင်း မှတ်နိုင်သည်။
💾 Backup
စာရင်းကို JSON ဖိုင်အဖြစ် ထုတ်ယူပြီး ပြန်သွင်းနိုင်သည်။

အသုံးပြုပုံ

  1. အခမဲ့ Demo ကိုဖွင့်ပါ။
  2. ပစ္စည်းအမည်၊ လက်ကျန်၊ ဝယ်ဈေးနဲ့ ရောင်းဈေးထည့်ပါ။
  3. အရောင်းစာရင်းကို မှတ်တမ်းတင်ပါ။
  4. အခါအားလျော်စွာ Backup ထုတ်ထားပါ။
အရေးကြီးသော ကန့်သတ်ချက်
ဒီ Demo က လက်ရှိဖုန်း Browser ထဲမှာပဲ ဒေတာသိမ်းထားတဲ့ အော့ဖ်လိုင်းအခြေခံစနစ်ဖြစ်သည်။ Cloud Sync၊ ဖုန်းအများကြား စာရင်းမျှဝေခြင်း၊ Receipt Printer နဲ့ အလိုအလျောက် Payment ချိတ်ဆက်မှု မပါသေးပါ။ ဖုန်း/Browser ဒေတာရှင်းမီ Backup ထုတ်ပါ။
